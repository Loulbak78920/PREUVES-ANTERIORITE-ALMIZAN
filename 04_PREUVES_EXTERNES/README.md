# Preuves externes

Tous les relevés portent `captured_at_utc` et les réponses brutes des services.

- `BASE_MAINNET_TRANSACTION.json` — appels JSON-RPC à `https://mainnet.base.org`
  (transaction, reçu, bloc, code du contrat).
- `RECU_DEPLOIEMENT_BASE_MAINNET.json` — reçu rédigé par l'auteur le
  2026-10-22, copié sans modification.
- `RAPPORT_VERIFICATION_DOIS.json` — résolution des trois DOIs déclarés.
- `HISTORIQUE_GIT_DEPOT_PUBLIC.json/.txt` — historique complet du dépôt public.
- `HISTORIQUE_GIT_DEPOT_PRIVE.json` — historique du dépôt privé (non vérifiable
  publiquement).
- `ACCES_PUBLIC_DEPOTS.json` — `git ls-remote` sur les deux dépôts.
